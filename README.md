# Discord AI Coding Agent Design

Single-page architecture proposal for a Discord-based AI coding agent.

Open `index.html` in a browser, or publish the repository with GitHub Pages.

## Core Idea

- Discord is the natural language UI.
- A cloud bot handles conversation, state, and approvals.
- A Synology NAS worker performs repository work in Docker.
- GitHub App permissions control repo access.
- Changes are delivered through branches and pull requests.
